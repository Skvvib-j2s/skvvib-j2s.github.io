## Description

Cet insert imprimé en 3D est un accessoire de rangement compatible avec **Code Names**. Il est prévu pour organiser les cartes "Nom de Code", les cartes "Clé" avec leur support, ainsi que les tuiles du jeu.

Le produit se compose de **4 modules indépendants**. Les modules sont amovibles et peuvent être utilisés directement sur la table pendant la partie, afin de faciliter le tri du matériel et la mise en place.

## Composition

- 2 modules pour les cartes "Nom de Code".
- 1 module pour les cartes "Clé" et le support de carte "Clé".
- 1 module pour les tuiles du jeu.
- 4 pièces imprimées en 3D au total.

## Caractéristiques

- Impression 3D FDM.
- Matière : PLA.
- Couleur par défaut : blanc.
- Version prévue pour cartes non sleevées.
- Modules indépendants, sans assemblage entre eux.
- Impression prévue sans support.
- Temps d'impression estimé : 3 h.
- Poids filament estimé : 150 g.
